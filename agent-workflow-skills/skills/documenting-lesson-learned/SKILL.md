# Document Lesson Learned

## Purpose

Convert experience into reusable knowledge. Every hard-won insight should be recorded so the next person (or future you) doesn't have to relearn it.

## When to Use

- After fixing a non-obvious bug
- After discovering a better way to do something
- When a common pitfall wasted significant time
- When a tool, library, or platform behaves unexpectedly

## How to Use

1. Identify the key insight or mistake
2. Write a concise, searchable title
3. Document the context, problem, and solution
4. Add prevention tips if applicable
5. Store in the memory bank

## Memory Bank

Document lessons in:
```
.agents/skills/documenting-lesson-learned/memory-bank/LEARNING.md
```

Use the `_template.md` for consistent formatting.

## Template

```markdown
## Lesson: [Short, searchable title]

- **Date learned**: YYYY-MM-DD
- **Context**: [What were you working on?]
- **Problem**: [What went wrong?]
- **Root cause**: [Why did it happen?]
- **Solution**: [What fixed it or what pattern works?]
- **Prevention**: [How to avoid this in the future?]
```

## Principles

- Be specific enough to be actionable
- Include versions and environment details when relevant
- Tag recurring themes for grouping
- Keep lessons atomic—one insight per entry
