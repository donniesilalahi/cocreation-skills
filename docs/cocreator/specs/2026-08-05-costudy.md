# costudy — design spec

**Date:** 2026-08-05 · **Status:** approved · **Ships in:** 0.13.0

## Purpose

Reverse-engineer another product's UI/UX into **buildable input** — screens, flows, information
hierarchy, and an inferred design system — captured from the user's own authenticated browser
session, primed by Mobbin, rendered as Open Design canvases plus a git-tracked ledger that
`cospecify` cites and `codraw` draws against.

Fills the gap Mobbin leaves: niche products, post-login screens, and the structural evidence
(a11y tree, computed tokens, network) that a screenshot library can't carry.

## Bootstrap — `study-manifest.json`

`.agents/workspace/study-manifest.json`, AI-owned. Draft + owner-confirm if missing (same pattern
as codraw's `design-manifest.json` and cocritique's `critique-manifest.json`). Fields:

```jsonc
{
  "target":        { "name": "Acme", "platform": "web|ios", "entryUrl": "https://…", "version": "captured 2026-08-05" },
  "job":           "The job we are studying them for — one sentence, JTBD phrasing",
  "flowsInScope":  ["onboarding", "checkout", "…"],          // 3–7. Not 'everything'.
  "authMode":      "live-session",                            // only supported value; never credentials
  "captureDir":    ".agents/workspace/studies/<target>-<date>/",
  "ledgerPath":    "docs/studies/<target>.study.json",        // git-tracked, in the CODE repo
  "odProjectId":   "…",                                       // optional; omit → HTML fallback
  "namingConvention": "<target>__<flow>__<screen>__<STATE>",   // STATE last, closed vocab
  "stateVocab":    ["default","empty","loading","error","success","filled","disabled"],
  "redaction":     { "maskSelectors": ["…"], "blurFaces": true, "scrubQueryParams": ["token","email"] },
  "mobbin":        { "searched": true, "coveredScreens": 0, "gaps": ["…"] }
}
```

Rationale: studying "everything" is the failure mode. The manifest forces a **job** and a bounded
flow list before any capture happens.

## Session adapter

**Primary: `browser-use` (CDP).** It attaches to the user's *running* Chrome, so the existing
logged-in profile reaches post-auth screens with zero credential handling.

**Opportunistic: `chrome-devtools` MCP** — richer a11y snapshots and network listing. Use only if a
probe (`list_pages`) shows it is attached to the same live browser; otherwise it launches an
isolated profile and sees a logged-out product.

**Excluded: Playwright MCP** — fresh profile, no session. Never used for costudy.

The skill runs the probe first and **states in its output which adapter it got**. If neither
adapter is available → `BLOCKED`, with an inbox action ask.

If a screen needs the human (log in, pay, accept ToS, solve a captcha): raise an `inbox/` **action**
ask, park that flow, and continue the other flows. Never stall; never handle credentials.

## Pipeline

### 0 — Recall & orient
Read `STATE.md`, `raw/`, the manifest, and recall lessons via `colearn`.

### 1 — Prime (Mobbin first)
`search_screens` / `search_flows` for the target **and** for its category; `search_sections` for
web marketing surfaces. Two outputs:
1. Free priors — pattern vocabulary and category baseline.
2. An explicit **gap list** — what Mobbin does *not* cover for this target. That gap list is the
   browser capture's work order. Record `mobbin.coveredScreens` and `mobbin.gaps` in the manifest.

Mobbin platform is `ios|web` only — no Android.

### 2 — Capture
Per screen, in one pass:
- full-page **screenshot**
- **a11y snapshot** (landmarks, headings, roles, names)
- **DOM subtree** for the main region
- **computed-style sample** on representative nodes (text, surface, control, elevated)
- **network requests** fired during the transition into this screen

Files land in `captureDir` under the manifest's segmented naming convention, **STATE last**,
closed state vocabulary — the same discipline as codraw, so a capture name maps 1:1 to an artboard
name later.

Human-paced traversal. No bulk crawl, no parallel hammering.

### 3 — Orient (nav graph)
- Nodes = screens. Edges = **the interaction that caused the transition** (element + action), not
  just "these two pages exist".
- Route discovery beyond what was walked: `sitemap.xml`, client-side router manifest, nav DOM
  links, in-page anchors.
- Every discovered-but-unwalked route is recorded as **`reachable-unvisited`**. This is the
  "understand the whole path possible" answer, and it is stated as a count in the verdict rather
  than quietly dropped.

### 4 — Understand (three passes)
1. **IA / hierarchy** — a11y landmarks + heading outline per screen → the information hierarchy.
2. **Pattern** — name each screen's pattern using the Mobbin taxonomy vocabulary where it applies;
   inventory the primitives (button, field, card, sheet, nav, …) with variants observed.
3. **System (inferred)** — derive from computed styles: color ramp, type scale, spacing rhythm,
   radii, shadow/elevation, motion durations & easing. **Always tagged `inferred`.** This is the
   highest-value and least-certain output; it must never be presented as the target's real tokens.

### 5 — Synthesize
- **Study ledger** — git-tracked JSON at `ledgerPath`, in the code repo (not the OD workspace),
  mirroring codraw's ledger shape so codraw can consume it directly. Entries are never deleted,
  only status-marked.
- **Memory-bank record** — `skills/costudy/memory-bank/YYYY-MM-DD-<target>-<flow>.md`.

Every finding carries an evidence tag: **`observed | inferred | assumed`** (borrowed from
cocritique). A conclusion resting on `assumed` can be no stronger than its weakest input.

### 6 — Render (canvases)
Open Design canvases, degrading to HTML/CSS artboards on disk when the OD MCP is absent (same
fallback contract as codraw — identical naming, ledger, and canvas set either way):

| Canvas | Shows |
|---|---|
| **Gallery** | every captured screen, grouped by flow, state-labelled |
| **Flow map** | the nav graph — nodes + causing-interaction edges + `reachable-unvisited` stubs |
| **IA sitemap** | data-driven hierarchy outline per screen, generated from the ledger |
| **Design-system sheet** | inferred ramp / scale / rhythm / radii / elevation / motion, `inferred`-tagged |
| **Pattern cards** | one card per pattern: what it does, what to steal, what to avoid, evidence link |

### 7 — Self-eval gate
Verdict: **`COMPLETE | PARTIAL | BLOCKED`**, with coverage numbers:
- flows captured / flows in scope
- screens captured / Mobbin-covered screens
- `reachable-unvisited` count
- assumed-tag ratio

`PARTIAL` is a legitimate exit and must name what is missing and why. iOS studies will be `PARTIAL`
on network/token evidence by construction (screenshots carry no computed styles) — that is stated,
not hidden.

## Ledger schema

Mirrors codraw's ledger so both are consumable by the same downstream reader. Per entry:

```jsonc
{
  "id": "acme__checkout__payment__error",     // matches the capture/artboard name
  "target": "Acme", "platform": "web",
  "flow": "checkout", "screen": "payment", "state": "error",
  "pattern": "payment-method-selection",       // Mobbin taxonomy where applicable
  "primitives": ["field","button","radio-card","inline-alert"],
  "ia": ["header/…","main/…"],                 // landmark + heading outline
  "tokens": { "…": "…" },                      // inferred sample
  "network": ["POST /api/pay"],                // observed calls on entry
  "evidence": { "screenshot": "…", "a11y": "…", "dom": "…", "mobbinUrl": "…" },
  "tag": "observed|inferred|assumed",
  "odArtifact": "…",                           // canvas/artboard ref when rendered
  "status": "captured|synthesized|rendered|superseded"
}
```

## Handoff contract

- `cospecify` cites a pattern as **`study:<id>`** in its spec.
- `codraw`'s `design-manifest.json` gains an optional **`referenceLedger`** pointer at a study
  ledger, so reference artboards resolve without re-deriving anything.
- `cocritique` may read the ledger as comparative evidence — tagged as competitor evidence, never
  as the bar.

## Guardrails (non-negotiable)

1. The user's **own** session only. Never request, store, or transmit credentials.
2. **Human-paced**, single-session traversal. No bulk crawling, no scraping at scale.
3. **Redaction pass before write** — mask other users' PII and the operator's own account
   identifiers in screenshots, DOM, and network records; scrub tokens from URLs.
4. Captures are **gitignored by default** (binary bloat + IP hygiene). Only the ledger and the
   memory-bank record are committed.
5. Honor ToS and `robots.txt`. Do not defeat bot protection, rate limits, or paywalls.
6. Output is **reference for informed design decisions**, not a clone-and-ship asset. Pattern cards
   carry "what to avoid" precisely to keep this a design input, not a copy machine.
7. If a target's terms forbid this kind of inspection, say so and stop — `BLOCKED`, not a
   workaround.
